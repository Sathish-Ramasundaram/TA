# CSS & Tailwind Learning Demos

This repository contains practice demos and exercises covering **CSS fundamentals**, **advanced CSS techniques**, and modern tooling with **SASS** and **TailwindCSS via PostCSS**.  
---

## 📂 Contents

### 1. CSS Fundamentals
- **Selectors & Cascading** → specificity, inheritance
- **Box Model** → margin, border, padding, content
- **Display & Visibility** → block, inline, inline-block, none, visibility: hidden  
👉 *Practice:* Simple page with divs styled using selectors and box model properties.

### 2. Layout & Positioning
- **Positioning** → static, relative, absolute, fixed, sticky
- **z-index** → layering elements
- **Float & Clear** → legacy layout technique
- **Text & Font Properties** → font-family, font-size, line-height, text-align, text-decoration  
👉 *Practice:* Small card layout with positioned elements and styled text.

### 3. Advanced CSS
- **Backgrounds & Borders** → gradients, border-radius, box-shadow
- **Transitions & Animations** → transition, @keyframes
- **Media Queries** → responsive design basics
- **Grid & Flexbox** → modern layout systems  
👉 *Practice:* Responsive 2‑column layout that changes to 1 column on small screens.

### 4. SASS
- Practiced using SASS for modular and maintainable CSS.

### 5. TailwindCSS
- **CDN Demo** → Quick setup using `<script src="https://cdn.tailwindcss.com"></script>`.
- **PostCSS Demo** → Full project setup with Tailwind as a PostCSS plugin.  
  Includes configs (`tailwind.config.js`, `postcss.config.mjs`), `src/input.css`, and generated `dist/output.css`.
