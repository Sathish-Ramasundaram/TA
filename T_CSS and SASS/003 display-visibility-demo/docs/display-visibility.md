# 🎨 CSS Display & Visibility

---

## 📦 CSS Display

Controls how an element behaves in the layout.

- **block** → Takes full width and starts on a new line  
- **inline** → Takes only the content width, does not start on a new line  
- **inline-block** → Behaves like inline but allows width and height to be set  
- **none** → Removes the element completely from the layout (no space reserved)

---

## 👁️ CSS Visibility

Controls whether an element is visible, but **keeps its space** in the layout.

- **visibility: hidden** → Element becomes invisible, but its space is still reserved
