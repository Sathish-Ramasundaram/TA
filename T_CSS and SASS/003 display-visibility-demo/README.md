# CSS Display & Visibility Demo

This project demonstrates how CSS `display` and `visibility` properties affect layout and visibility.

## Concepts Covered
- display: block
- display: inline
- display: inline-block
- display: none
- visibility: hidden

## How to Run
1. Open the project folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## Learning Outcome
- Understand how elements behave in layout
- Know the difference between `display: none` and `visibility: hidden`
- Choose the right display type for UI design
