# CSS Text & Font Properties Demo

This project demonstrates basic text and font styling using CSS.

## Properties Covered
- font-family
- font-size
- line-height
- text-align
- text-decoration

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## What to Observe
- Different fonts applied to text
- Text size differences
- Increased spacing between lines
- Center-aligned text
- Link underline removed

## Learning Outcome
- Style text clearly and readably
- Improve content presentation
- Understand common text properties
