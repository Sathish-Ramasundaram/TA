# Text & Font Properties (Beginner Level)

Text and font properties control how text looks and appears on a web page — such as its font style, size, spacing, and alignment.

## 1. `font-family`

Defines which font is used for the text.

```css
font-family: Arial, sans-serif;
```

## 🔹 2. `font-size`

Controls how big or small the text is.

```css
font-size: 16px;
```

## 🔹 3. `line-height`

Controls the vertical space between lines of text.

✔ Improves readability  
✔ Very important for paragraphs and body text  

```css
line-height: 1.5;
```

## 🔹 4. `text-align`

Controls the horizontal alignment of text.

```css
text-align: left;
text-align: center;
text-align: right;
text-align: justify;
```

## 🔹 5. `text-decoration`

Adds decorative lines to text.

**Common uses:**
- Remove underline from links  
  ```css
  text-decoration: none;
```
