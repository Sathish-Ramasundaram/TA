# SASS Demo

This project demonstrates **CSS Preprocessor (SASS)** features:
- Variables
- Nesting
- Mixins

## Concepts Covered
- Using variables for colors, font sizes, and padding
- Nesting selectors to organize styles
- Creating reusable mixins with parameters
- Compiling SCSS to CSS

## How to Run
1. Install SASS: `npm install -g sass`
2. Open the folder in VS Code
3. Compile SCSS: `sass style.scss style.css --watch`
4. Open `index.html` in the browser

## What to Observe
- Navbar with nested list items and hover effect
- Cards with consistent border-radius from mixin
- Button with reusable style and hover effect

## Learning Outcome
- Understand SASS syntax: variables, nesting, mixins
- Maintain cleaner, reusable CSS
- Use preprocessors in modern web projects
