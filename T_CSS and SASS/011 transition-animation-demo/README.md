# CSS Transitions & Animations Demo

This project demonstrates how to make elements move and change smoothly using CSS.

## Concepts Covered
- **Transition:** smooth property changes on hover or state change
- **@keyframes Animation:** controlled multi-step animations that can repeat

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## What to Observe
- Button changes color and slightly grows when hovered (transition)
- Green box continuously bounces up and down (animation)

## Learning Outcome
- Make interactive UI with smooth effects
- Understand the difference between transitions and animations
- Control timing, speed, and repetition of animations
