# CSS Positioning Demo

This project demonstrates how CSS positioning works using real examples.

## Position Types Covered
- static
- relative
- absolute
- fixed
- sticky

## Description
Each box visually represents a different `position` value so you can see:
- How elements move
- How they affect layout
- How scrolling behaves

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## What to Observe
- Static elements follow normal flow
- Relative moves from original position
- Absolute positions inside parent
- Fixed stays on screen while scrolling
- Sticky sticks at the top while scrolling

## Learning Outcome
- Understand document flow
- Know when to use each position type
- Build better layouts and UI elements
