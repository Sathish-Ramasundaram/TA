# Backgrounds & Borders Demo

This project demonstrates how to use CSS to style backgrounds and borders.

## Concepts Covered
- Backgrounds: solid color, linear gradient, radial gradient
- Borders: width, style, color, border-radius
- Box-shadow: adding depth and visual effect

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## What to Observe
- Box 1: solid background and simple border
- Box 2: gradient background and rounded corners
- Box 3: radial gradient with shadow

## Learning Outcome
- Create visually appealing boxes
- Use gradients for smooth color transitions
- Add rounded corners and shadows for depth
