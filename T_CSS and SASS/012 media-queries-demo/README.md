# Media Queries Demo

This project demonstrates how to make a web page responsive using CSS Media Queries.

## Concepts Covered
- Media Queries: `@media` rules for different screen sizes
- Responsive design: adapt layout for desktop, tablet, and mobile
- Flexbox layout for arranging elements

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file
4. Resize your browser window to see boxes adjust

## What to Observe
- Desktop: 3 boxes side by side
- Tablet (<= 768px): boxes stack vertically, width smaller
- Mobile (<= 480px): boxes take full width

## Learning Outcome
- Understand responsive design basics
- Use media queries to adapt styles for different screen sizes
- Combine flexbox and media queries for flexible layouts
