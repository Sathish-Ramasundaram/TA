# Responsive 2-Column Layout

This project demonstrates a simple responsive layout using **Flexbox** and **Media Queries**.

## Concepts Practiced
- Flexbox: for creating a flexible 2-column layout
- Media queries: switching to 1 column on smaller screens
- Padding, background colors, and border-radius for styling

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file
4. Resize your browser window to see the layout change

## What to Observe
- On large screens: two columns side by side
- On screens smaller than 768px: columns stack vertically (1 column)
- Smooth responsive behavior using Flexbox and media queries

## Learning Outcome
- Build responsive layouts
- Understand Flexbox column distribution
- Apply media queries for different screen sizes
