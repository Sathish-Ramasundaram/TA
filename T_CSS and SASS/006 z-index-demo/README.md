# CSS z-index Demo

This project demonstrates how the CSS `z-index` property controls the stacking order of overlapping elements.

## What is z-index?
`z-index` controls which element appears on top when elements overlap.

## Important Rules
- Works only on positioned elements
- Higher value appears on top
- Can use negative values
- Affected by stacking context

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## What to Observe
- Blue box (z-index: 3) appears on top
- Green box (z-index: 2) appears in the middle
- Red box (z-index: 1) appears at the bottom

## Learning Outcome
- Understand element layering
- Learn when and how to use z-index
- Avoid common overlapping issues
