# CSS Selectors & Cascading Demo

This project demonstrates how CSS applies styles using:
- Selectors
- Specificity
- Cascading rules
- Inheritance

## Concepts Covered
- Universal, Element, Class, ID selectors
- Inline styles
- Specificity priority
- Inheritance from parent elements
- !important rule

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → **Open with Live Server**
   (or double-click the file)

## Expected Behavior
- Blue text from element selector
- Green text from class selector
- Red text from ID selector
- Purple text from inline style
- Brown color inherited from `.container`
- `!important` overrides normal rules

## Learning Outcome
You will understand:
- Why some styles override others
- How browsers decide which CSS rule wins
- How inheritance works in CSS
