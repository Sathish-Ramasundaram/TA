# Card Layout Practice

This project helps practice CSS concepts by building a simple card layout.

## Objective
- Create a card layout with:
- A card container
- An image at the top
- A title and description
- A “Read More” button
- Use positioning (relative/absolute) to place elements
- Style text with font-family, font-size, text-align, text-decoration

## Concepts Practiced
- Box model: margin, padding, border, border-radius
- Positioning: relative (card container), absolute can be added
- Text & font properties: font-family, font-size, line-height, text-align, text-decoration
- Styling: colors, shadows, hover effects
- Images in cards

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## Learning Outcome
- Build visually appealing cards
- Understand positioning and layering
- Style text and buttons effectively
