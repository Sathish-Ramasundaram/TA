# Flexbox & Grid Demo

This project demonstrates how to create modern layouts using **Flexbox** and **Grid**.

## Concepts Covered
- Flexbox for 1-dimensional layout (row or column)
- Grid for 2-dimensional layout (rows and columns)
- Common properties: justify-content, align-items, gap, grid-template-columns

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## What to Observe
- Flexbox: 3 boxes aligned in a row with spacing around them
- Grid: 6 boxes arranged in 3 columns and 2 rows
- Both layouts are responsive to container width

## Learning Outcome
- Understand the difference between Flexbox and Grid
- Build flexible, modern web layouts
- Apply alignment and spacing techniques effectively
