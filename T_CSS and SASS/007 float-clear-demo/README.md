# CSS Float & Clear Demo

This project explains how the legacy CSS `float` and `clear` properties work.

## What is float?
`float` moves an element to the left or right and allows other content to wrap around it.

## What is clear?
`clear` prevents elements from sitting next to floated elements.

## Concepts Covered
- float: left
- float: right
- clear: both
- Float side effects
- Parent container collapsing

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## Key Learning
- Floats remove elements from normal flow
- Clear fixes layout issues caused by floats
- Float is a legacy layout technique
