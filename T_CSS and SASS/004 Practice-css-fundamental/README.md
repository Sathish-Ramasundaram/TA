# CSS Selectors & Box Model Practice

This practice project helps you apply CSS selectors and box model properties together.

## Concepts Practiced
- Element selector (`div`)
- Class selector (`.box`)
- Multiple classes (`.box.special`)
- ID selector (`#unique-box`)
- Margin, padding, border
- box-sizing: border-box

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## Practice Goals
- Observe how different selectors apply styles
- Understand spacing using margin and padding
- See how ID overrides class and element styles

## Try This
- Change margin values and observe spacing
- Remove `box-sizing: border-box`
- Add inline styles and see priority changes
