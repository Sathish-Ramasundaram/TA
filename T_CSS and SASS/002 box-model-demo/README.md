# CSS Box Model Demo

This project demonstrates the CSS Box Model and how spacing works around elements.

## What is the Box Model?
Every HTML element consists of:
- Content
- Padding
- Border
- Margin

## Properties Explained
- `content`: Actual text or image
- `padding`: Space inside the border
- `border`: Wraps padding and content
- `margin`: Space outside the element

## box-sizing
- `content-box` (default): width excludes padding & border
- `border-box`: width includes padding & border (recommended)

## How to Run
1. Open the folder in VS Code
2. Open `index.html`
3. Right-click → Open with Live Server
   OR double-click the file

## Learning Outcome
- Understand spacing inside and outside elements
- Learn how box size is calculated
- Use `box-sizing: border-box` for clean layouts
